# Oppgave

Lag en komplett Odoo 16 Community-modul kalt `donation_vipps`.

Målet er å lage et **Proof of Concept** for å lære hvordan Odoo mottar webhooks. Modulen skal **ikke** integrere mot Vipps API ennå. Den skal kun motta en HTTP POST, lagre innholdet i databasen og gjøre det synlig i Odoo.

Modulen skal følge OCA sine retningslinjer for struktur og kodekvalitet.

# Datamodell

Lag modellen

```
donation.vipps.webhook
```

med følgende felter:

| Felt             | Type     |
| ---------------- | -------- |
| name             | Char     |
| received_at      | Datetime |
| method           | Char     |
| path             | Char     |
| remote_addr      | Char     |
| headers          | Text     |
| payload          | Text     |
| processed        | Boolean  |
| processing_error | Text     |

Bruk

```
received_at = fields.Datetime(default=fields.Datetime.now)
```

og

```
processed = fields.Boolean(default=False)
```

Navnet (`name`) kan automatisk genereres som

```
Webhook YYYY-MM-DD HH:MM:SS
```

eller ved hjelp av en sequence.

Sorter etter

```
received_at desc
```

---

# Controller

Lag en HTTP-controller.

Route:

```
/vipps/webhook
```

Krav:

* auth="public"
* csrf=False
* methods=["POST"]
* type="http"

Controlleren skal

1. lese request body
2. lese alle HTTP-headere
3. lese request path
4. lese HTTP-metode
5. lese klient-IP
6. lagre alt i modellen
7. returnere HTTP 200

Ingen behandling av JSON utover lagring.

Payload skal lagres nøyaktig slik den mottas.

Headers kan lagres som pretty-printed JSON.

Bruk Odoo sin logger.

# Test

Etter at modulen er installert skal følgende fungere:

```
curl -X POST \
  http://localhost:8069/vipps/webhook \
  -H "Content-Type: application/json" \
  -d '{"event":"payment","amount":250}'
```

Dette skal opprette en ny post i

```
Vipps → Webhooks
```

med hele payloaden lagret.
